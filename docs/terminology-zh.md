# 中文术语对照（README.zh-CN 用）

> 作者确定的原则（2026-10-20）：**没有稳定、公认中文译名的术语一律保留英文**，不做硬译。
> 有公认译名的，首次出现写「中文（English）」，此后用中文。书名、卷名与本书体系专名保留英文。

## B. 保留英文（无稳定中文译名，硬译会不准确）

| English | 说明 |
|---|---|
| perfectoid（perfectoid space） | 中文有「完美胚」「狀似完備」「完美化」多种写法，无统一译名 |
| prismatic（prismatic cohomology, prism） | 「棱镜」「棱柱」两种写法并存 |
| condensed / solid（condensed mathematics） | 「凝聚数学」「凝聚态数学」并存，且易与物理混淆 |
| almost mathematics / almost purity | 未见中文文献的固定译法 |
| diamond, v-sheaf, pro-étale | 专名 |
| étale（étale cohomology） | 中文数学文献普遍直接写 étale |
| motive（motivic） | 「动机」「母题」「动形」并存，多数文献保留 motive |
| site | 「景」「位形」并存 |
| tilting / untilting | 在 perfectoid 语境下保留英文 |
| IUT（inter-universal Teichmüller theory） | 专名 |
